# Mini LinkedIn API

## 1. Project Overview
This project is a RESTful API built with Laravel that simulates a simplified LinkedIn-like platform.  
It provides authentication, profile management, job offers, and candidature features using JWT authentication.

---

## 2. Technologies Used
- Laravel (PHP Framework)
- MySQL
- JWT Authentication
- Postman (API testing)
- Git / GitHub

---

## 3. Requirements
- PHP >= 8.1
- Composer
- MySQL
- Laravel 10+
- Postman

---

## 4. Installation

```bash
git clone https://github.com/hihihahi17-lab/mini-linkedin-api.git
